# Implementation Plan: Add Images to Customer Room Endpoints

## Overview

Add image support to customer room API endpoints so that when customers call GET /customer/rooms/\*, they receive room and room type images in the response.

## Current State

- Database already has `RoomImage` and `RoomTypeImage` models with proper relationships
- Image service exists for managing images (upload, delete, etc.)
- Customer room endpoints currently don't include images in responses

## Changes Required

### 1. Update Room Service (`room.service.ts`)

Add image includes to the following methods:

#### A. `getRoomById()`

- Include `images` (ordered by sortOrder)
- Include `roomType.images` (ordered by sortOrder)

#### B. `searchAvailableRooms()`

- Include `images` (ordered by sortOrder)
- Include `roomType.images` (ordered by sortOrder)

#### C. `searchAvailableRoomsByDate()`

- Include `images` (ordered by sortOrder)
- Include `roomType.images` (ordered by sortOrder)

#### D. `isRoomAvailableForDates()`

- Include `images` (ordered by sortOrder)
- Include `roomType.images` (ordered by sortOrder)

### 2. Create Customer Image Controller (Optional)

Create `customer.image.controller.ts` with read-only endpoints:

```
GET /customer/rooms/:roomId/images - Get all images for a room
GET /customer/room-types/:roomTypeId/images - Get all images for a room type
```

This provides a dedicated endpoint if needed for lazy loading or separate image requests.

### 3. Update Route Documentation

Update Swagger documentation in `customer/room.route.ts` to reflect that images are now included in responses.

## Implementation Steps

1. ✅ Analyze current codebase structure
2. ⏳ Update Room Service to include images
3. ⏳ Create Customer Image Controller (if beneficial)
4. ⏳ Create Customer Image Routes (if beneficial)
5. ⏳ Update API documentation
6. ⏳ Test the endpoints

## Benefits

- Customers can see room and room type images directly in search results
- Single API call gets all necessary data (no need for separate image requests)
- Consistent with existing admin endpoints structure
- Mobile app can display beautiful room galleries

## Notes

- Images are ordered by `sortOrder` field (ascending)
- Only include images that exist (Cloudinary URLs)
- Response includes full image metadata (url, secureUrl, thumbnailUrl, width, height, format, isDefault)
